## What This Is

A fully interactive satirical website built to demonstrate how conspiracy theory propaganda operates — including the visual design language, rhetorical tricks, and logical fallacies commonly used to make false claims appear credible.

Every piece of "evidence" is fabricated or uses deliberate logical fallacies. The footer of the site labels the manipulation techniques being used.

## Techniques Demonstrated

| Technique | Example on Site |
|---|---|
| Confirmation bias | Only evidence "against" is shown |
| Appeal to ignorance | "No one has proven he's NOT dead" |
| Circular reasoning | "Being debunked is suspicious" |
| False authority | "Anonymous AI tool (from Telegram)" |
| Emotional bypass | "WAKE UP", "DO YOUR OWN RESEARCH" |
| Unfalsifiability | Any counter-evidence = part of the cover-up |
| Redaction theater | Black bars create false mystery |

## Deploy to GitHub Pages

1. Fork or clone this repo
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Save — your site will be live in ~60 seconds

## Files

```
index.html      ← main site (rename from netanyahu_conspiracy.html)
README.md       ← this file
_config.yml     ← GitHub Pages config
.nojekyll       ← prevents Jekyll processing
```

## Local Preview

Just open `index.html` in any browser — no build step needed.
